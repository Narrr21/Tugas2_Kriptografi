Dokumentasi API Custom Block Cipher

Dokumentasi resmi untuk antarmuka pemrograman aplikasi (API) pustaka kriptografi Custom Block Cipher (128-bit). Pustaka ini mengimplementasikan cipher Feistel 16-ronde dengan S-box dinamis berbasis kunci (key-dependent S-box), mendukung 5 mode operasi dan padding PKCS#7.

1. Python API (cipher.py)

Wrapper tingkat tinggi berbasis ctypes untuk integrasi Python dan GUI Streamlit.

Konstanta & Eksepsi

  • cipher.BLOCK_SIZE (int): Ukuran blok cipher, bernilai tetap 16 (128 bit).
  • cipher.MODES (list[str]): Mode operasi yang didukung: ["ECB", "CBC", "CFB", "OFB", "CTR"].
  • cipher.CipherError: Dilemparkan ketika proses enkripsi/dekripsi native gagal (misal padding tidak valid atau mode tidak dikenal).
  • ValueError: Dilemparkan saat panjang key atau iv bukan 16 byte.

cipher.encrypt

Melakukan enkripsi buffer biner menggunakan kunci, mode operasi, dan IV tertentu.

Penjelasan Parameter

Parameter Tipe Data Keterangan
data bytes Plaintext yang akan dienkripsi (panjang sembarang).
key bytes Kunci enkripsi simetris 128-bit (wajib tepat 16 byte).
mode str Mode operasi: "ECB", "CBC", "CFB", "OFB", atau "CTR".
iv bytes Initialization Vector / nilai awal counter (wajib tepat 16 byte). Pada mode "ECB", nilai ini diabaikan namun tetap harus 16 byte.

Nilai Kembalian (Output)

  • Tipe Data: bytes
  • Keterangan: Ciphertext terenkripsi (dengan padding PKCS#7 jika mode ECB/CBC).

cipher.decrypt

Melakukan dekripsi ciphertext kembali menjadi plaintext.

Penjelasan Parameter

Parameter Tipe Data Keterangan
data bytes Ciphertext yang akan didekripsi.
key bytes Kunci dekripsi simetris 128-bit (wajib tepat 16 byte).
mode str Mode operasi: "ECB", "CBC", "CFB", "OFB", atau "CTR". Harus sama dengan saat enkripsi.
iv bytes Initialization Vector 16 byte yang sama saat enkripsi.

Nilai Kembalian (Output)

  • Tipe Data: bytes
  • Keterangan: Plaintext asli setelah padding dihilangkan (unpadded).

Contoh Penggunaan (Python)

import cipher

# 1. Siapkan Kunci (16 byte), IV (16 byte), dan Plaintext
key = bytes.fromhex("0123456789ABCDEFFEDCBA9876543210")
iv  = bytes.fromhex("A5A5A5A5A5A5A5A55A5A5A5A5A5A5A5A")
plaintext = "Kriptografi 128-bit dengan MkDocs API".encode("utf-8")

# 2. Enkripsi (Mode CBC)
ciphertext = cipher.encrypt(plaintext, key=key, mode="CBC", iv=iv)
print("Ciphertext (HEX):", ciphertext.hex().upper())

# 3. Dekripsi
decrypted = cipher.decrypt(ciphertext, key=key, mode="CBC", iv=iv)
print("Decrypted text  :", decrypted.decode("utf-8"))

# 4. Error Handling
try:
    salah_kunci = b"terlalu_pendek"
    cipher.encrypt(plaintext, key=salah_kunci, mode="ECB", iv=iv)
except ValueError as e:
    print("Validasi gagal:", e)

2. C++ API Core (block_cipher.hpp)

API native performa tinggi yang diimplementasikan dalam namespace kripto.

Tipe Data Utama

namespace kripto {
    enum class CipherMode { ECB, CBC, CFB, OFB, CTR };

    struct Block128 {
        std::uint64_t hi{0};
        std::uint64_t lo{0};
    };
}

kripto::encryptBuffer / kripto::decryptBuffer

Enkripsi dan dekripsi buffer berukuran dinamis secara otomatis menangani padding dan rantai blok.

std::vector<std::uint8_t> encryptBuffer(
    const std::vector<std::uint8_t>& data,
    Block128 masterKey,
    CipherMode mode = CipherMode::CBC,
    Block128 iv_or_counter = {}
);

std::vector<std::uint8_t> decryptBuffer(
    const std::vector<std::uint8_t>& data,
    Block128 masterKey,
    CipherMode mode = CipherMode::CBC,
    Block128 iv_or_counter = {}
);

Penjelasan Parameter

Parameter Tipe Data Keterangan
data const std::vector<std::uint8_t>& Buffer data masukan (plaintext / ciphertext).
masterKey kripto::Block128 Kunci master 128-bit (hi dan lo).
mode kripto::CipherMode Enum mode operasi: ECB, CBC, CFB, OFB, CTR. Default: CBC.
iv_or_counter kripto::Block128 IV / initial counter 128-bit. Default: blok nol.

Nilai Kembalian (Output)

  • Tipe Data: std::vector<std::uint8_t>
  • Keterangan: Vektor biner hasil proses enkripsi / dekripsi.

Operasi Primitif Blok Tunggal

Untuk operasi tingkat rendah langsung pada satu blok 128-bit:

Block128 encryptBlock(Block128 plaintext, Block128 masterKey);
Block128 decryptBlock(Block128 ciphertext, Block128 masterKey);
  • Input: plaintext / ciphertext (1 blok 128-bit), masterKey (128-bit).
  • Output: Block128 (blok hasil transformasi Feistel 16 ronde).

Contoh Penggunaan (C++)

#include <iostream>
#include <vector>
#include "block_cipher.hpp"

int main() {
    // Kunci 128-bit: 0x0123456789ABCDEF, 0xFEDCBA9876543210
    kripto::Block128 key{0x0123456789ABCDEFULL, 0xFEDCBA9876543210ULL};
    kripto::Block128 iv{0xA5A5A5A5A5A5A5A5ULL, 0x5A5A5A5A5A5A5A5AULL};

    std::vector<std::uint8_t> data = {'H', 'a', 'l', 'o', ' ', 'D', 'u', 'n', 'i', 'a'};

    // Enkripsi
    auto ct = kripto::encryptBuffer(data, key, kripto::CipherMode::CBC, iv);

    // Dekripsi
    auto pt = kripto::decryptBuffer(ct, key, kripto::CipherMode::CBC, iv);

    std::cout << "Panjang terdekripsi: " << pt.size() << " bytes\n";
    return 0;
}

3. Penjelasan Tambahan

Ringkasan Mode Operasi

Mode Kebutuhan IV Perlu Padding PKCS#7? Toleran Kerusakan Transmisi
ECB (Electronic Codebook) Tidak (diabaikan) Ya (kelipatan 16 byte) Tidak ada propagasi error antar-blok
CBC (Cipher Block Chaining) Ya (16 byte acak) Ya (kelipatan 16 byte) Error merusak blok saat ini & 1 bit blok berikutnya
CFB (Cipher Feedback) Ya (16 byte) Tidak (Stream mode) Error mempropagasi hingga 1 blok penuh
OFB (Output Feedback) Ya (16 byte unik) Tidak (Stream mode) Error 1 bit di ciphertext hanya merusak 1 bit plaintext
CTR (Counter Mode) Ya (Counter unik) Tidak (Stream mode) Mendukung enkripsi/dekripsi paralel & akses acak

Skema Padding PKCS#7

Pada mode blok (ECB & CBC), jika data masukan berukuran $N$ byte, padding sebanyak $P = 16 - (N \pmod{16})$ byte ditambahkan ke akhir data, di mana setiap byte padding bernilai $P$. Jika data sudah tepat kelipatan 16 byte, 1 blok penuh (16 byte bernilai 0x10) ditambahkan.

Keamanan Kunci dan Thread Safety

  • Key-dependent S-box: S-box di-generate ulang per sesi melalui algoritma Fisher-Yates dengan byte kunci sebagai entropi.
  • Thread Safety: Fungsi encryptBuffer dan decryptBuffer bersifat re-entrant dan aman dipanggil secara konkuren antar-thread.
